# AuthNRequest

## Description
The authentication request (AuthNRequest) is a request from the service provider (SP) to the identity provider (IdP) to authenticate the user. The AuthNRequest is an XML document that contains information about the user and the SP. The AuthNRequest is sent from the SP to the IdP to request that the user be authenticated.
